安全问题报告 / Reporting security concerns

涉及疑似漏洞、凭据泄露或可能暴露私人数据的问题，请发送邮件至 644245542@qq.com，不要先创建包含细节的公开 Issue。

请说明受影响的软件版本、Windows 版本、问题影响及最小复现步骤。优先提供不含真实业务数据的复现；不要发送真实密码、Token、Cookie 或私钥。需要更大附件时，先在邮件中描述内容。

普通使用报错、文档纠错和功能建议请使用反馈入口。本页提供报告渠道，不构成响应时限、奖励或长期版本支持承诺。

English

Report suspected vulnerabilities, credential exposure or private-data disclosure to 644245542@qq.com. Do not open a public issue containing sensitive details first.

Include the affected application version, Windows version, impact and minimal reproduction steps using nonconfidential data. Do not send real passwords, tokens, cookies or private keys. Describe large attachments before sending them. Use Support for ordinary usage errors and documentation corrections. This reporting channel does not promise a response deadline, bounty or long-term version support.
