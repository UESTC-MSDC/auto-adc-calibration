# 使用手册

Auto ADC Calibration · 中文操作参考 · 2026 年 10 月

本手册供日常操作和查阅使用，说明项目管理、数据准备、模型训练、测试与结果保存。首次使用时，建议配合[图解教程](quick-start.zh-CN.md)完成基础流程。

**基础流程：准备数据 → 训练模型 → 独立测试。** 搜索、剪枝、量化和硬件评估按任务需要使用。

> **适用说明**　本手册面向 Windows 桌面版。界面名称以当前软件为准；应用启动文件为 `KAN Workbench.exe`。演示设置用于熟悉操作，不构成性能承诺。

## 1. 阅读与项目管理

### 选择阅读入口

| 使用场景 | 阅读内容 |
| --- | --- |
| 安装并启动软件 | [安装与运行](installation.zh-CN.md) |
| 完成第一次操作 | [图解教程](quick-start.zh-CN.md) |
| 查阅常用设置 | 本手册第 2～4 节 |
| 核对文件格式或处理报错 | [数据格式](data-format.zh-CN.md)、[故障排查](troubleshooting.zh-CN.md) |

### 建立独立项目

1. 启动软件，在左侧选择 **新建**，指定独立、可写的项目目录。
2. 将原始采集保存在便于长期维护的位置，并使用有意义的项目及实验名称，例如“单音校准演示”“基准训练”。
3. 继续已有工作时选择 **打开**，核对项目及所需数据是否可用。

### 识别数据用途

| 本手册称呼 | 用途与选择方式 |
| --- | --- |
| 原始采集 | ADC 输出的原始码字文件；用于预处理或模型测试 |
| 训练数据集 | 预处理后供训练使用的数据；优先使用软件自动关联的目录 |
| 独立测试数据 | 未参与训练及方案选择的原始采集；用于确认模型表现 |
| 任务结果 | 一次任务生成的模型、配置、图表和报告 |

**目录选择原则：** 训练时选择预处理结果根目录或软件关联的训练数据集；测试时选择原始采集或软件生成的原始测试入口。自动编号用于存储管理，无需记忆或手工重命名。

> **保存要求**　项目可以引用外部原始数据。迁移或备份时，应同时保存这些文件及完整任务结果；仅复制一个模型文件可能不足以继续后续操作。

## 2. 数据准备与预处理

### 核对输入

一份 TXT 或 CSV 文件对应一组采集，一行对应一个采样点。各级码字按列保存，最终输出码字使用单列。文件宜为无表头、无时间戳及序号列的纯数值数据。

| 设置 | 填写依据 |
| --- | --- |
| 数据来源 | 选择“各级码字”或“最终输出码字” |
| 位宽与编码 | 与文件一致，核对有符号／无符号及十进制／二进制 |
| 级数与级间增益 | 仅各级码字模式需要，按实际 ADC 填写 |
| 通道数 | 单通道填 1；交织采集填写实际通道数 |
| 信号类型 | 与采集一致，选择单音或双音 |
| 采样率 | 填写完整输出序列的总采样率 |

### 执行预处理

1. 打开 **数据**，选择原始采集目录，完成上述设置。
2. 配置测试集比例、抽样比例和校准质量。演示可采用 **20% / 100% / 快速**；正式任务按实验要求设置。
3. 选择 **检查数据**。检查通过后，选择 **开始预处理**。
4. 完成后查看结果区，确认训练数据集与测试数据划分。

**完成检查：** 任务正常结束，输出目录可访问，原始采集仍保存在原位置。保留软件生成的配置与配套文件，避免只复制单个内部子目录。

> **操作提示**　首次使用时保留其余默认设置。使用自定义权重时，按界面提示先完成权重扫描；配置锁定后需要修改时，通过“重新开始”重新检查。

文件编码、目录结构及读取范围的详细约定见[数据格式](data-format.zh-CN.md)。最终输出码字模式不要求与各级码字模式生成完全相同的子目录。

## 3. 模型训练与测试

### 训练模型

进入 **配置 → 浮点模型 → 模型训练**，确认自动关联的训练数据集，并核对信号类型和采样率。模型设置首次保留默认值。

| 常用设置 | 含义 | 演示建议 |
| --- | --- | --- |
| 每组读取行数 | 每份采集的读取上限；0 表示全部 | 32768；短文件读取可用行 |
| 训练轮数 | 本次训练轮次 | 20 |
| 批大小 | 每次处理的样本数量 | 256 |
| 学习率 | 训练更新设置 | 0.001 |
| 运行设备／数值精度 | 本次任务的计算设置 | auto／保留默认 |

选择 **开始训练**，在 **训练** 页查看实际设备、进度和损失曲线。显存不足时可降低批大小；需要续训时，使用 **继续训练** 并选择对应任务。

### 独立测试

1. 打开 **测试**，选择需要评估的模型。
2. 选择独立保留的原始采集，核对信号类型、采样率与读取范围。
3. 选择 **开始测试**，逐组查看校准前后的频谱与指标。

| 结果 | 判读要点 |
| --- | --- |
| SNDR / SFDR | 在相同条件下比较校准前后变化，关注全部采集 |
| 频谱 | 查看主信号、杂散与噪声的变化 |
| 训练损失 | 用于观察训练过程；校准效果以独立测试为准 |
| 任务状态 | 区分完成、未达标、失败、超时和未执行 |

> **比较条件**　比较模型时，保持采集、采样率和读取范围一致。参与模型搜索或参数选择的数据，不再作为最终独立测试数据。

## 4. 可选工作流程

基础流程完成后，可根据任务选择下列功能。每次变更模型后，建议重新测试并保存对应结果。

| 功能 | 操作顺序 | 完成检查 |
| --- | --- | --- |
| 模型搜索 | 选择数据 → 设置目标和预算 → 开始搜索 | 选择结果，以独立数据复测 |
| 模型剪枝 | 选择来源模型与验收数据 → 开始剪枝 | 查看验收状态并复测 |
| 剪枝训练 | 从对应剪枝结果进入 → 选择匹配数据 → 训练 | 保存本次结果并复测 |
| 位宽扫描 | 选择模型和数据 → 扫描 → 应用方案 | 继续量化训练与验收 |
| 量化训练 | 检查模型兼容性 → 核对设置 → 开始训练 | 查看最终验收，再复测 |

### 设置说明

- **增益保留：** 针对校准效果。例如 80% 不表示保留 80% 的连接。
- **位宽扫描：** 产出可供应用的方案；应用后仍需完成量化训练和最终检查。
- **模型兼容性：** 按界面提示选择受支持的来源，保留完整配套文件。

### 硬件与 ASIC

进入 **硬件** 前，先配置所需外部工具或可选 ASIC 扩展。ASIC 流程按 **逻辑综合 → 布局布线与验证 → 实例功耗评估** 依次进行。环境准备与支持范围见[硬件说明](hardware.zh-CN.md)。

> **结果范围**　“仅生成源码”只表示完成导出。功能检查、综合、实现和功耗是不同阶段；报告需结合运行条件使用，不能直接作为芯片实测或制造签核结论。

## 5. 结果保存与维护

### 保存可复查的实验

使用页面中的 **打开目录** 定位任务结果。建议按“项目名称 + 实验目的”组织记录，保留以下材料。

| 材料 | 保存目的 |
| --- | --- |
| 模型及完整任务目录 | 保留匹配配置和后续操作所需文件 |
| 原始采集及数据划分 | 复查训练与测试使用了哪些数据 |
| 采样率、读取范围和运行设置 | 确认结果比较条件 |
| 图表、报告及软件版本 | 复查、交流或引用结果 |

软件生成的原始测试入口可能引用外部文件。移动项目后，应核对原始数据是否仍可访问。不同实验分别保存，避免覆盖需要比较的结果。

### 升级与排查

1. 升级前关闭软件，并备份项目与外部原始数据。
2. 将新旧软件放在不同目录，先使用项目副本验证。
3. 遇到问题时，记录版本、操作步骤和错误信息，再查阅[故障排查](troubleshooting.zh-CN.md)。

迁移与回退说明见[升级与备份](upgrade.zh-CN.md)。提交截图或日志前，请去除无关的个人路径及敏感数据。
