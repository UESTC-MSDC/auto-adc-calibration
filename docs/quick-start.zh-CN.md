# 快速上手：完成一次 ADC 校准

[安装说明](installation.zh-CN.md) · [完整教程](user-guide.zh-CN.md) · [配置参考](reference.zh-CN.md) · [English](quick-start.md)

使用 `examples/tutorial/raw/` 中的 20 份六级流水线 ADC 仿真采集，每份 8192 行。文件保持在同一目录，由预处理自动分集；使用兼容的 NVIDIA GPU 训练。

## 1. 建立项目

运行 `KAN Workbench.exe`，选择 **新建**，指定项目名称和可写目录。在 **数据** 页选择 `examples/tutorial/raw/`。

## 2. 预处理并自动分集

| 设置 | 值 |
| --- | --- |
| 数据来源／模型输入 | 各级码字／各级码字 |
| 输入编码／输出格式 | 有符号十进制／CSV |
| 通道数／信号类型 | 1／单音 |
| ADC 级数／各级位宽 | 6／2.5、2.5、2.5、2.5、2.5、4 bit |
| 到下一级增益 | 4、4、4、4、4 |
| 码字合成／补偿基准 | 按级间增益自动计算／初始参数合成 |
| 抽样比例／校准质量 | 100%／快速 |
| 测试集比例 | **20%** |

依次选择 **检查数据 → 开始预处理**。完成后得到 `train_16`、`test_4` 和 `raw_test`。软件按完整文件随机留出 4 组；每次划分的编号可能不同。保留原始 CSV，`raw_test` 保存其引用。

## 3. 使用 GPU 训练

进入 **配置 → 浮点模型 → 模型训练**。确认训练数据关联到 `train_16`，按下表设置后选择 **开始训练**。

| 设置 | 值 |
| --- | --- |
| 总采样率／每组读取行数 | 1 GHz／8192 |
| 窗口数量／隐藏层 | 1／12 |
| 网格数 grid／样条阶数 k／基础函数 | 3／2／identity |
| 训练轮数／批大小 | 120／256 |
| 优化器／学习率／权重衰减 | AdamW／0.001／0.0001 |
| 调度器／余弦周期／最低学习率 | cosine／120／0.000001 |
| 目标归一化／早停 | 开启／关闭 |
| 运行设置：计算设备／数值精度／随机种子 | **cuda**／float64／1 |

在 **训练** 页确认实际设备为 CUDA。设备不可用时先完成[GPU 排错](troubleshooting.zh-CN.md#gpu)，再启动训练。

## 4. 独立测试

进入 **测试**，选择本次训练模型；原始采集入口选择预处理生成的 **`raw_test`**。核对单音、1 GHz、每组 8192 行，选择 **开始测试**。报告应包含此次留出的 4 组采集。

本次验证中，全部留出组的 SNDR 提升为 **34.15-34.38 dB**，SFDR 提升为 **49.16-50.93 dB**。逐组数值与条件见[样例验证记录](../examples/README.md#results)。这是低噪声、固定器件误差的仿真示例；实测数据的改善幅度取决于误差和噪声条件。

## 5. 保存结果

使用 **打开目录** 保存完整项目、模型任务、测试报告及原始数据。后续使用自有采集、优化模型或迁移项目时，按[完整教程](user-guide.zh-CN.md)操作。
