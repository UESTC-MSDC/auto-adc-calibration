使用手册

Auto ADC Calibration · 操作参考 · 文档 v3.5.0

v3.5.0 新增按位拆列的补码二进制输入，并改进权重扫描、预处理缓存和 Windows 深路径模型参照读取。新编码的列顺序和设置见数据格式。

首次使用请先完成Pipelined ADC 图解教程。本手册用于查设置、换数据和继续已有任务；示例沿用“Pipelined 入门”项目。

基本顺序：预处理 → 训练 → 独立测试。 搜索、剪枝、量化和硬件评估按目标选择。

1. 建项目与选数据

先分清三个位置

位置 存放什么 本例
软件目录 EXE、Worker 和运行资源 完整解压的软件包
项目目录 本次设置、模型和任务结果 Pipelined 入门
原始采集目录 供预处理和测试读取的原始码字 raw-train、raw-test

选择 新建 建立项目；继续工作时选择 打开。原始采集可放在项目外，但项目引用的文件需长期保留。备份时同时保存项目和外部数据。

每个页面选哪个目录

操作 应选择 示例
数据预处理 训练用原始采集目录 examples/pipelined/raw-train
模型训练 预处理结果根目录或自动关联的数据集 包含 inputs/baseline/reference 的目录
模型测试 独立原始采集或有效的原始测试入口 examples/pipelined/raw-test

预处理目录中的角色名称详见数据格式。自动生成的编号用于管理任务，无需手工重命名。

完成检查： 知道训练和测试分别使用哪些原始文件；本例测试 003 未进入训练目录。

2. 核对预处理设置

按采集填写

设置 决定什么 pipelined 示例
数据来源与编码 如何读取码字 各级码字、有符号十进制
级数与每级位宽 每列属于哪一级 6 级；前 5 级 2.5 bit，后端 4 bit
到下一级增益 各级码字的名义合成关系 五个增益均为 4
通道数与信号类型 采样顺序与信号处理方式 1、单音
测试集比例 是否从当前目录另分测试文件 0%；本例已另留 raw-test
抽样比例与校准质量 预处理使用的数据量和计算设置 100%、快速

先 检查数据，通过后 开始预处理。本例得到 4 组训练数据；测试集比例为 0% 时不自动创建原始测试入口。

设置与预期不一致时

  • 列数报错：检查是否多了时间戳、表头或序号列。
  • 参数锁定：选择 重新开始，修改后再次检查。
  • 使用自定义权重：按界面要求先完成权重扫描，再预处理。
  • 只有最终输出码字：填写输出位宽、符号与文件编码；不需要各级增益。

完成检查： 数据检查与预处理均完成，训练目录及配套配置可访问。保留整个结果目录，不拼接不同任务的内部文件。

3. 训练与独立测试

训练时主要改什么

进入 配置 → 浮点模型 → 模型训练，先确认训练数据、信号类型和总采样率，再填写训练参数。

设置 用途 入门值
总采样率 计算频谱的频率刻度 1 GHz
每组读取行数 每份文件的读取上限，0 表示全部 8192
训练轮数 完整训练数据的迭代次数 20
批大小 每次训练更新处理的样本数 256
学习率／目标归一化 更新幅度／训练目标缩放 0.001／开启
运行设备／数值精度 本次计算方式 cpu／float64

选择 开始训练，在 训练 页查看实际设备与进度。已有对应任务需要续训时，使用 继续训练；另做对照实验时保存为独立任务。

如何判断校准有没有改善

在 测试 页选训练模型与独立原始采集，核对采样率和读取行数后 开始测试。本例使用 raw-test/capture_003.csv；教程记录 SNDR 53.37 → 55.86 dB、SFDR 60.53 → 61.96 dB。

SNDR 反映总体噪声与失真，SFDR 反映最大杂散；相同条件下数值越高越好。逐组比较频谱与指标，不只看最好的一组。

训练损失用于观察训练过程，独立测试用于判断新数据表现。比较多个模型时保持采集、采样率、读取范围和信号模式一致。

完成检查： 模型与测试报告一一对应；未将参加过调参的数据称为最终独立测试数据。测试采样率随模型读取，信号模式与读取行数仍需核对。

4. 按目标优化或评估硬件

选一条需要的路径

目标 操作顺序 查看什么
选择模型配置 模型搜索 → 选择结果 → 独立测试 目标是否满足、各采集表现
缩小模型 模型剪枝 → 查看验收 → 按需剪枝训练 → 复测 剪枝结果与精度变化
选择量化方案 位宽扫描 → 应用方案 → 量化训练 → 复测 最终验收与校准指标
运行硬件评估 硬件 → 配置工具 → 执行相应流程 每个已运行阶段的状态与报告

例如要比较基准模型和剪枝模型，分别保存任务，并对同一批独立采集运行测试。不要用更换测试文件或缩短读取范围来代替模型改善。

三个容易混淆的结果

  • 增益保留 80%： 指校准改善的保留目标，不表示保留 80% 的连接。
  • 位宽扫描通过： 表示得到候选方案；应用后仍需量化训练和最终验收。
  • 仅生成源码： 表示导出 RTL；仿真、综合、物理实现和功耗需分别执行。

ASIC 使用独立扩展，按 逻辑综合 → 布局布线与验证 → 实例功耗评估 进行。准备条件及结果解释见硬件说明。

完成检查： 保存当前实验的状态和条件。失败、取消、超时与未执行分别记录；未运行的检查不计为通过。

5. 保存、迁移与排查

保存一份能复查的实验

用 打开目录 找到任务结果；备份整个任务及其原始数据，记录以下信息。

记录项 pipelined 示例
项目与实验 Pipelined 入门／Pipelined 基准训练
数据用途 001、002、004、005 训练；003 测试
计算条件 CPU、20 轮、1 GHz、8192 行
模型与报告 本次训练模型、对应独立测试报告
软件与数据版本 实际软件版本、本版文档样例修订 04

仅保存截图不足以恢复任务；仅复制模型也可能缺少预处理配方和其他配套文件。

迁移或升级

先关闭任务并备份项目与外部数据；新版软件放在独立目录，用项目副本验证。移动项目后检查数据引用，具体步骤见升级与备份。

遇到问题

按故障排查找到对应现象。提供版本、操作步骤、错误文本及必要的已脱敏截图；用仿真样例复现时更容易排除数据差异。

完成检查： 换一个目录打开项目副本后，仍能找到原始数据、模型和报告。许可与联系见软件使用许可及首页。

反馈时请区分应用版本和文档版本，按获取帮助提供最小复现信息。
