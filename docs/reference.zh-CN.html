配置与功能参考

首页 · 快速上手 · 完整教程

本页按功能集中说明参数含义、输入约束与输出用途。教程使用的值是样例配置，自有采集应按实际规格填写。

1. 输入格式与数据目录

原始文件为 CSV/TXT，一份文件对应一组采集，一行一个时间采样点。使用纯数值；避免表头、时间戳、索引列、小数码字和非有限值。

各级码字

一列对应一级；级数与通道数分别设置。教程的六列来自 5 个 2.5-bit 级和一个 4-bit 后端，前五列为 −4～4，末列为 −8～7 的整数；五个名义级间增益均为 4。2.5 bit 是级结构标签。

编码 数据要求
有符号十进制 各级按自身位宽和结构提供有符号整数
偏移二进制 按对应无符号码域导入，由所选编码解释
补码二进制（按位拆列） 同一码字最高位到最低位排列；每列 1 bit，只含 0/1，首列为符号位

补码拆位输入由程序处理符号位。采用自定义列权重时，初始权重按列逐级减半，操作顺序为 检查数据 → 扫描初始权重 → 开始预处理。编码警告应回到采集格式检查。

最终输出码字

每行提供一个整码，填写输出位宽 N（1～32 bit）和编码，无需填写各级增益。

编码 格式或范围
无符号十进制 0～2^N−1
有符号十进制 −2^(N−1)～2^(N−1)−1
固定宽度二进制 每行恰好 N 位；有符号数据按补码解释

交织、信号与采样率

多路交织数据按 lane 0 到 lane L−1 循环逐行排列，行数应构成完整帧。总采样率使用合并输出序列的采样率；两路各 700 MS/s 时填写 1.4 GHz。

信号类型选择单音或双音。双音频率提示使用 f/fs，例如 100 MHz、1 GHz 采样率对应 0.1。其他信号的处理与评估需要相应适用方法。

预处理产物

目录或文件 用途
train_N N 组训练采集的数据根目录
test_M M 组留出采集的预处理数据
raw_test 留出原始采集的测试入口，可能只保存引用
inputs 模型输入；兼容名称 code
baseline 补偿基准；兼容名称 actual
reference 拟合得到的训练参考；兼容名称 ideal
adc_config.json、配方文件 输入规格、重建和后续测试所需信息

训练选完整的训练根目录。角色文件按采集编号配对，同一角色的新旧目录名不要混用。最终输出模式可能只有 inputs 和 reference。测试比例为 0% 时，训练角色目录直接位于预处理根目录。

2. 预处理参数

参数 作用 教程值
原始数据目录 当前任务读取的采集文件 examples/fullband50/raw/
数据来源／模型输入 输入码字的解释和模型输入形式 各级码字
输入编码 数值和符号解释 有符号十进制
级数／位宽／增益 ADC 名义结构与码字合成 6 级；2.5×5+4；增益 4×5
通道数 单通道或交织通道数量 1
码字合成 自动名义权重或自定义权重 按级间增益自动计算
补偿基准来源 初始参数合成或适用的粗校准结果 初始参数合成
抽样比例 预处理计算使用的数据比例 100%
校准质量 可用校准计算档位 专业
全部 IGE／全部 DAC 级间增益与 DAC 误差估计 均开启
测试集比例 按完整采集文件随机留出的比例 20%

测试比例大于 0% 时至少需要两组完整采集。划分以检查结果为准，每次重新检查可能产生不同划分；比较模型时复用同一预处理任务。

3. 训练与运行参数

参数 含义 教程值
每组读取行数 每份文件的读取上限；0 表示全部 32768
总采样率 频谱横轴与频率换算的依据 1 GHz
窗口数量 一个输入窗口包含的相邻采样点数 3
隐藏层 每层节点数，多个值用逗号分隔 5
grid／k／基础函数 KAN 网格、样条阶数和基础分支 5／3／identity
训练轮数 对训练数据迭代的轮数 20
批大小 每次参数更新使用的窗口数 512
优化器／学习率／权重衰减 参数更新方式与幅度 AdamW／0.001／0.0001
余弦周期／最低学习率 学习率衰减周期和下限 20／0.000001
目标归一化 对训练目标进行标准化 开启
早停 按训练损失变化提前结束训练 关闭
计算设备 cuda 为 NVIDIA GPU；auto 自动选择设备 auto；本次实际为 CUDA
数值精度／随机种子 浮点计算类型与随机初始化 auto／1；本次实际为 float64

有兼容 NVIDIA GPU 时选择 cuda，并核对任务实际设备。不同随机划分、设备与软件环境可能造成结果差异。每组读取行数、输入窗口和批大小是三个独立参数。

4. 测试、搜索、剪枝与量化

功能 输入 输出与检查重点
独立测试 完整模型任务、原始采集或 raw_test 逐组频谱、SNDR、SFDR、ENOB
模型搜索 训练数据、目标指标及预算 候选结构、状态和可复测模型
模型剪枝 适用基准模型及验收数据 规模变化、改善保留情况、验收状态
位宽扫描 适用模型与方案选择数据 位宽候选与限制条件
量化训练 已应用的位宽方案、配套训练数据 量化模型、浮点参照、最终验收

测试采样率从模型读取，信号模式与读取行数仍需核对。参加模型选择的数据不能继续充当最终独立测试集。“增益保留”描述校准改善的保留目标，模型连接数另看规模统计。

5. 硬件功能

RTL 仿真与综合

在 硬件 → 仿真与综合 选择通过兼容性检查的模型，保留量化任务、浮点参照及预处理配方。选择输出语义：需要校正量时选补偿值输出，需要完整结果时选校准值输出。

“仅生成源码”产出 RTL 及配套材料。仿真和综合需要配置相应外部工具及许可；实际精度评估还需独立原始采集。分别检查功能对拍、精度和综合报告。

ASIC 实现

在 管理 ASIC 扩展 中安装、导入兼容离线包或连接已有环境。准备 WSL2、可用内存及至少 20 GiB 安装空间，实验输出另计；运行完整环境自检。

阶段 结果解释
逻辑综合 当前工艺与约束下的网表、面积、时序和运行状态
布局布线与验证 兼容综合结果的物理实现及对应验证
实例功耗评估 已验证电路在指定输入活动和覆盖范围下的估计

比较报告时保持工艺、时钟、模型接口和输入活动一致。目标时钟是约束，实际性能以结果为准；数字校准电路功耗不包含整个 ADC 或板级系统。

失败、取消和超时后保留任务，使用界面恢复兼容检查点。工具、工艺、模型或约束改变时，重新运行受影响阶段。未执行的检查保留为未评估，硬件报告的验证范围以实际完成阶段为准。
