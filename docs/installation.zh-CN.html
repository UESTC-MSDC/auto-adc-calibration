安装说明

首页 · English · 快速上手

1. 检查运行环境

使用 Windows x64。软件包自带 Python 和必要运行库，无需安装 Python、MATLAB 或 CUDA 开发工具包。

有兼容的 NVIDIA GPU 时，使用 CUDA 训练。 打开软件后检查设置页的 CUDA 信息；设备未识别时按GPU 排错处理。AMD、Intel GPU 不属于本 CUDA 发行包的训练设备。

下载、解压、原始数据和训练结果分别占用空间，按 Release 附件大小及数据规模预留磁盘空间。实测环境记录见CHANGELOG，不代表已覆盖所有硬件组合。

2. 下载并校验

打开最新正式发行版，下载同一版本的全部 Windows x64 分卷及 SHA256SUMS.txt。将 .zip.001、.zip.002 等分卷放在同一目录。

在下载目录打开 PowerShell：

Get-ChildItem -File 'Auto-ADC-Calibration-*-Windows-x64.zip.*' |
    Get-FileHash -Algorithm SHA256

将每个文件的散列与同版 SHA256SUMS.txt 对照。GitHub 自动生成的 Source code (zip / tar.gz) 是文档仓库快照；Windows 程序位于命名为 Windows-x64 的发行附件中。

3. 完整解压并启动

使用支持分卷的工具打开 .001，解压到独立目录，例如 D:/ADC-Tools/Workbench/。解压后应包含：

KAN Workbench.exe
KAN Worker.exe
_internal/
configs/
Documentation/

保持文件相对位置，在解压目录运行 KAN Workbench.exe。Worker 由主程序调用。

新建项目时选择另外的可写目录，例如 D:/ADC-Projects/Tutorial/。在 配置 → 浮点模型 → 模型训练 → 运行设置 中将 计算设备 设为 cuda；任务开始后核对实际设备。auto 可能选择 CPU，教程使用明确的 cuda 设置。

4. 获取当前文档和样例

在本仓库选择 Code → Download ZIP，解压后检查 examples/tutorial/raw/ 中的 20 份 CSV。它们与本次教程配套；安装包内其他样例保留各自配置。

打开 index.html 阅读离线文档，或使用 downloads/ 内的 PDF。按快速上手完成第一次校准。

RTL/ASIC 功能另需相应工具；准备条件见配置与功能参考。已有项目的升级与备份见完整教程。
