# 配置与功能参考

[首页](../README.zh-CN.md) · [快速上手](quick-start.zh-CN.md) · [用户手册](user-guide.zh-CN.md)

本页按功能集中说明参数含义、输入约束与输出用途。教程使用的值是样例配置，自有采集应按实际规格填写。

## 1. 输入格式与数据目录

<a id="data"></a>

原始文件为 CSV/TXT，一份文件对应一组采集，一行一个时间采样点。使用纯数值；避免表头、时间戳、索引列、小数码字和非有限值。

### 各级码字

一列对应一级；级数与通道数分别设置。教程的六列来自 5 个 2.5-bit 级和一个 4-bit 后端，前五列为 −4～4，末列为 −8～7 的整数；五个理想级间增益均为 4。2.5 bit 是级结构标签。

| 编码 | 数据要求 | 简要说明 |
| --- | --- | --- |
| 有符号十进制 | 各级按自身位宽和结构提供有符号整数 | 一列对应一级，保留负号 |
| 偏移二进制 | 每列为对应位宽的固定 N 位 0/1 字符串 | 中间码表示零，如 8 位 `10000000` 表示 0 |
| 补码二进制（按位拆列） | 同一码字从最高位到最低位排列，每列 1 bit | 每列只含 0/1，首列为符号位 |

补码拆位输入由程序处理符号位。采用自定义列权重时，初始权重按列逐级减半，操作顺序为 **检查数据 → 扫描初始权重 → 开始预处理**。编码警告应回到采集格式检查。

### 最终输出码字

<a id="final-output-codes"></a>

每行提供一个整码，填写输出位宽 N（1～32 bit）和编码，无需填写各级增益。

| 编码 | 数据要求 | 简要说明 |
| --- | --- | --- |
| 无符号十进制 | 0～2^N−1 | N 为输出位宽，如 8 bit 对应 0～255 |
| 有符号十进制 | −2^(N−1)～2^(N−1)−1 | 如 8 bit 对应 −128～127 |
| 固定宽度二进制 | 每行恰好 N 位 | 保留前导零，有符号数据按补码解释 |

固定宽度二进制应保留前导零，不添加表头、空格或分隔符。例如 8 位无符号码字 `00000101` 表示 5；8 位有符号补码 `11111111` 表示 -1。

软件按 MSB 到 LSB 自动拆成 N 列，每列 1 bit，后续模型也按位输入，与手动拆成 N 列的处理一致。补码符号位按既有规则转换。拆位不会增加原始采集的信息量，也不能恢复未记录的内部级码字。

右侧使用 **自定义列权重**，默认依次为 `1、0.5、0.25……`，第一个通道最高位作为权重参考。操作顺序为 **检查数据 → 扫描初始权重 → 开始预处理**。权重必须为有限正数；无效权重导入会报错并保留当前配置。

“**补偿基准来源**”选择“**粗校准后合成**”时使用已接受的精确权重；选择“**初始参数合成**”时，权重按原有规则取最近的 2 的整数次幂。原始数据测试沿用模型保存的输入格式自动拆位，无需手动拆列；已有整码输入模型仍按其保存的格式测试。

### 交织、信号与采样率

多路交织数据按 lane 0 到 lane L−1 循环逐行排列，行数应构成完整帧。总采样率使用合并输出序列的采样率；两路各 700 MS/s 时填写 1.4 GHz。

信号类型选择单音或双音。双音频率提示使用 `f/fs`，例如 100 MHz、1 GHz 采样率对应 `0.1`。其他信号的处理与评估需要相应适用方法。

### 预处理产物

| 目录或文件 | 用途 | 简要说明 |
| --- | --- | --- |
| `train_N` | N 组训练采集的数据根目录 | 训练时选择整个目录 |
| `test_M` | M 组留出采集的预处理数据 | 与训练采集分开保存 |
| `raw_test` | 留出原始采集的测试入口 | 可能只保存引用，需保留原始文件 |
| `inputs` | 模型输入 | 兼容旧名称 `code` |
| `baseline` | 补偿基准 | 兼容旧名称 `actual` |
| `reference` | 拟合得到的训练参考 | 兼容旧名称 `ideal` |
| `adc_config.json`、配方文件 | 保存输入规格与重建设置 | 后续测试沿用，需与任务一起保留 |

训练选完整的训练根目录。角色文件按采集编号配对，同一角色的新旧目录名不要混用。旧的整码输入任务可能只有 `inputs` 和 `reference`，按任务配方读取，无需手工补目录。测试比例为 0% 时，训练角色目录直接位于预处理根目录。

## 2. 预处理参数

<a id="preprocessing"></a>

| 参数 | 教程值 | 含义 | 简要说明 |
| --- | --- | --- | --- |
| 原始数据目录 | `examples/fullband50/raw/` | 当前任务读取的采集目录 | 一份文件对应一组采集 |
| 数据来源／模型输入 | 各级码字 | 输入码字的解释与模型输入形式 | 按实际记录选择各级码字或最终输出码字 |
| 输入编码 | 有符号十进制 | 数值与符号的解释方式 | 必须与原始文件的编码一致 |
| 级数 | 6 | 流水线 ADC 的级数 | 各级码字输入时填写 |
| 各级位宽 | 前五级 2.5，末级 4 | 每级的结构或量化位宽 | 2.5 bit 是级结构标签 |
| 级间增益 | 前五级均为 4 | 相邻级之间的理想增益 | 最后一级为后端，不填写到下一级增益 |
| 通道数 | 1 | 单通道或交织通道数量 | 多路交织时填写实际通道数 |
| 码字合成 | 按级间增益自动计算 | 各列码字合成输出时的权重来源 | 整码拆位输入使用自定义列权重 |
| 补偿基准来源 | 初始参数合成 | 模型预测补偿量所叠加的基准 | 可选择初始参数或已接受的粗校准结果 |
| 抽样比例 | 100% | 训练侧数据用于权重扫描和粗校准的抽取比例 | 通常按采集抽取并留验证集；单组时拆分连续片段 |
| 校准质量 | 专业 | 粗校准的搜索与迭代预算 | 按耗时需求选择快速、标准或专业 |
| 全部 IGE | 开启 | 启用级间增益误差估计 | 用于粗校准，最终后端不参与 |
| 全部 DAC | 开启 | 启用 DAC 误差估计 | 用于粗校准，最终后端不参与 |
| 测试集比例 | 20% | 按完整采集文件随机留出的比例 | 0% 表示不从当前目录留出测试集 |

测试比例大于 0% 时至少需要两组完整采集。划分以检查结果为准，每次重新检查可能产生不同划分；比较模型时复用同一预处理任务。

## 3. 训练与运行参数

| 参数 | 教程值 | 含义 | 简要说明 |
| --- | --- | --- | --- |
| 每组读取行数 | 32768 | 每份文件的读取上限 | 0 表示读取全部行 |
| 总采样率 | 1 GHz | 频谱横轴与频率换算的依据 | 交织输入填写合并后的总采样率 |
| 窗口数量 | 3 | 一个输入窗口包含的连续时间步数 | 单通道按采样点计，交织输入按完整帧计 |
| 隐藏层 | 5 | 每个隐藏层的节点数 | `5` 表示一层五个节点；多层用逗号分隔 |
| grid | 5 | 样条网格的区间数 | 控制样条的分段数量 |
| k | 3 | 每段样条的多项式次数 | 3 表示三次样条 |
| 基础函数 | `identity` | KAN 的基础分支函数 | `identity` 为线性，`silu` 为 SiLU，`zero` 关闭该分支 |
| 训练轮数 | 20 | 对训练数据迭代的总轮数 | 早停启用时可能提前结束 |
| 批大小 | 512 | 每次参数更新使用的窗口数 | 增大通常会增加显存或内存占用 |
| 优化器 | `AdamW` | 更新模型参数的算法 | 按配置选择 `AdamW` 或 `Adam` |
| 学习率 | 0.001 | 每次更新模型参数的步长尺度 | 过大可能不稳定，过小可能收敛较慢 |
| 权重衰减 | 0.0001 | 对模型参数施加的衰减强度 | 用于限制参数数值幅度，0 表示关闭 |
| 余弦周期 | 20 | 学习率降至下限所用的训练轮数 | 到达周期后保持最低学习率 |
| 最低学习率 | 0.000001 | 余弦衰减后的学习率下限 | 与初始学习率共同确定衰减范围 |
| 目标归一化 | 开启 | 对训练的补偿目标进行标准化 | 改善优化尺度，预测输出仍为实际补偿量 |
| 早停 | 关闭 | 训练损失持续无足够改善时停止 | 按训练损失判断；阈值和耐心轮数控制触发 |
| 计算设备 | `auto`；本例实际为 CUDA | 训练使用的 CPU 或 GPU | `auto` 自动选择；`cuda` 指定 NVIDIA GPU |
| 数值精度 | `auto`；本例实际为 `float64` | 训练使用的浮点数据类型 | 与 ADC 位宽及硬件量化位宽分别设置 |
| 随机种子 | 1 | 控制训练初始化等随机过程 | 固定后便于比较；不控制预处理的数据划分 |

有兼容 NVIDIA GPU 时选择 `cuda`，并核对任务实际设备。不同随机划分、设备与软件环境可能造成结果差异。每组读取行数、输入窗口和批大小是三个独立参数。

### 损失显示

<a id="loss-display"></a>

损失卡片、训练曲线和导出的损失图默认显示原始单位损失，悬停可查看标准化损失。目标标准化影响优化尺度；显示原始单位不会改变训练过程或最佳模型的选择依据。没有保存原始单位指标的旧记录会保留相应标识，不应直接与新记录的原始单位损失比较。

## 4. 测试、搜索、剪枝与量化

| 功能 | 输入 | 输出 | 简要说明 |
| --- | --- | --- | --- |
| 独立测试 | 完整模型任务、原始采集或 `raw_test` | 逐组频谱、SNDR、SFDR、ENOB | 使用未参与训练或模型选择的数据 |
| 模型搜索 | 训练数据、目标指标及预算 | 候选结构、状态和可复测模型 | 搜索结束后复测候选模型 |
| 模型剪枝 | 适用基准模型及验收数据 | 规模变化、改善保留情况、验收状态 | 同时检查模型规模与校准效果 |
| 位宽扫描 | 适用模型与方案选择数据 | 位宽候选与限制条件 | 选择符合精度和资源要求的方案 |
| 量化训练 | 已应用的位宽方案、配套训练数据 | 量化模型、浮点参照、最终验收 | 保留配套浮点模型，便于比较与硬件验证 |

测试采样率从模型读取，信号模式与读取行数仍需核对。**参加模型选择的数据不能继续充当最终独立测试集**。“增益保留”描述校准改善的保留目标，模型连接数另看规模统计。

## 5. 硬件功能

<a id="hardware"></a>

### RTL 仿真与综合

<a id="vivado-setup"></a>

**工具安装**：从 [AMD 官网](https://www.amd.com/zh-cn/support/downloads/adaptive-socs-and-fpgas/development-tools/2025-2.html)下载 Vivado，安装时包含 XSim 和 Virtex-7 器件支持。项目已有 Vivado 2025.2 的验证记录；当前综合检查目标为 `xc7vx485tffg1157-1`，请按 AMD 对所选版本与器件的要求配置适用许可。软件不附带 Vivado。路径设置见[首次准备](user-guide.zh-CN.md#hardware-setup)。

在 **硬件 → 仿真与综合** 选择通过兼容性检查的模型，保留量化任务、浮点参照及预处理配方。选择输出语义：需要校正量时选 **补偿值输出**，需要完整结果时选 **校准值输出**。

“**仅生成源码**”无需 Vivado，产出 RTL 及配套材料；“**生成并验证**”使用 XSim 仿真和 Vivado 综合。实际精度评估还需独立原始采集。分别检查功能对拍、精度和综合报告。

### ASIC 实现

**额外环境**：WSL2 和独立 ASIC 扩展。扩展准备 Linux、Docker Engine、Yosys、OpenROAD、KLayout、Icarus Verilog、Verilator 及工艺资源；无需 Vivado 或 Docker Desktop。可选 IHP SG13G2（130 nm）、Nangate45（45 nm）或全部工艺，两者共用工具镜像。

按[首次准备](user-guide.zh-CN.md#hardware-setup)启用 WSL2，再在 **管理 ASIC 扩展** 中 **在线安装** 并完成自检。准备可用内存及 **至少 20 GiB 安装空间**，实验输出另计。已有环境可选择 **连接已有环境**；离线导入需取得与软件版本兼容、包含所需仿真器的完整扩展包。

| 阶段 | 输出 | 简要说明 |
| --- | --- | --- |
| 逻辑综合 | 网表、面积、时序和运行状态 | 结果对应当前工艺与约束 |
| 布局布线与验证 | 物理实现及对应验证结果 | 需要兼容的综合结果 |
| 实例功耗评估 | 数字校准电路的功耗估计 | 仅覆盖已验证电路与指定输入活动 |

比较报告时保持工艺、时钟、模型接口和输入活动一致。目标时钟是约束，实际性能以结果为准；数字校准电路功耗不包含整个 ADC 或板级系统。

失败、取消和超时后保留任务，使用界面恢复兼容检查点。工具、工艺、模型或约束改变时，重新运行受影响阶段。未执行的检查保留为未评估，硬件报告的验证范围以实际完成阶段为准。
