# 配置与功能参考

[首页](../README.zh-CN.md) · [快速上手](quick-start.zh-CN.md) · [用户手册](user-guide.zh-CN.md)

表中“教程值”用于复现[快速上手](quick-start.zh-CN.md)；自有数据按实际 ADC 规格设置。

## 1. 输入格式与数据目录

<a id="data"></a>

CSV/TXT 文件每份保存一组采集，每行对应一个采样点。只保留整数码字，不含表头、时间戳、序号、空值或非有限值。

### 各级码字

一列对应一级 ADC，通道数按交织路数填写。教程的六列对应五个 2.5-bit 级和一个 4-bit 后端，码字范围见[预处理参数](#preprocessing)。

| 编码 | 数据要求 | 简要说明 |
| --- | --- | --- |
| 有符号十进制 | 各级按自身位宽和结构提供有符号整数 | 一列对应一级，保留负号 |
| 偏移二进制 | 每列为对应位宽的固定 N 位 0/1 字符串 | 中间码表示零，如 8 位 `10000000` 表示 0 |
| 补码二进制（按位拆列） | 同一码字从最高位到最低位排列，每列 1 bit | 每列只含 0/1，首列为符号位 |

程序自动处理补码符号位。使用自定义列权重时，初始权重按列逐级减半，依次点击 **检查数据 → 扫描初始权重 → 开始预处理**。

### 最终输出码字

<a id="final-output-codes"></a>

每行提供一个整码，填写输出位宽 N（1～32 bit）和编码，无需填写各级增益。

| 编码 | 数据要求 | 简要说明 |
| --- | --- | --- |
| 无符号十进制 | 0～2^N−1 | N 为输出位宽，如 8 bit 对应 0～255 |
| 有符号十进制 | −2^(N−1)～2^(N−1)−1 | 如 8 bit 对应 −128～127 |
| 固定宽度二进制 | 每行恰好 N 位 | 保留前导零，有符号数据按补码解释 |

二进制码字中不添加空格或分隔符。例如 8 位无符号码字 `00000101` 表示 5；8 位有符号补码 `11111111` 表示 -1。

软件按 MSB 到 LSB 拆成 N 列，每列 1 bit；模型按位输入，补码符号位由程序处理。

选择 **自定义列权重**，默认依次为 `1、0.5、0.25……`，以第一个通道的最高位为参考。依次点击 **检查数据 → 扫描初始权重 → 开始预处理**。权重必须为有限正数。

**补偿基准来源** 选择 **粗校准后合成** 时使用已接受的精确权重；选择 **初始参数合成** 时，权重取最近的 2 的整数次幂。原始数据测试按模型保存的输入格式处理，无需手动拆列。

### 交织、信号与采样率

多路交织数据按 lane 0 到 lane L−1 循环逐行排列，行数应构成完整帧。总采样率使用合并输出序列的采样率；两路各 700 MS/s 时填写 1.4 GHz。

信号类型选择单音或双音。双音频率提示使用 `f/fs`，例如 100 MHz、1 GHz 采样率对应 `0.1`。

### 预处理产物

| 目录或文件 | 用途 | 简要说明 |
| --- | --- | --- |
| `train_N` | N 组训练采集的数据根目录 | 训练时选择整个目录 |
| `test_M` | M 组留出采集的预处理数据 | 供剪枝验收；原始数据测试选择 `raw_test` |
| `raw_test` | 留出原始采集的测试入口 | 可能只保存引用，需保留原始文件 |
| `inputs` | 模型输入 | 与基准、参考按采集编号配对 |
| `baseline` | 补偿基准 | 与模型预测补偿量相加得到校准输出 |
| `reference` | 拟合得到的训练参考 | 与基准之差为训练目标 |
| `adc_config.json`、配方文件 | 保存输入规格与重建设置 | 后续测试沿用，需与任务一起保留 |

测试集比例为 0% 时，直接选择预处理根目录进行训练。

## 2. 预处理参数

<a id="preprocessing"></a>

| 参数 | 教程值 | 含义 | 简要说明 |
| --- | --- | --- | --- |
| 原始数据目录 | `examples/fullband50/raw/` | 当前任务读取的采集目录 | 一份文件对应一组采集 |
| 数据来源／模型输入 | 各级码字 | 输入码字的解释与模型输入形式 | 按实际记录选择各级码字或最终输出码字 |
| 输入编码 | 有符号十进制 | 数值与符号的解释方式 | 必须与原始文件的编码一致 |
| 级数 | 6 | 流水线 ADC 的级数 | 各级码字输入时填写；最终输出码字模式无需填写 |
| 各级位宽 | 前五级 2.5，末级 4 | 每级的结构或量化位宽 | 本例 2.5-bit 级码字为 −4～4，4-bit 后端为 −8～7 |
| 级间增益 | 前五级均为 4 | 相邻级之间的理想增益 | 最后一级为后端，不填写到下一级增益 |
| 通道数 | 1 | 交织通道数量 | 单通道填 1；多通道按 lane 顺序循环排列 |
| 码字合成 | 按级间增益自动计算 | 各列码字合成输出时的权重来源 | 整码拆位输入使用自定义列权重 |
| 补偿基准来源 | 初始参数合成 | 模型预测补偿量所叠加的基准 | 可选择初始参数或已接受的粗校准结果 |
| 抽样比例 | 100% | 用于权重扫描和粗校准的训练数据比例 | 按采集抽取并保留验证数据；单组采集按连续片段划分 |
| 校准质量 | 专业 | 粗校准的搜索与迭代预算 | 按耗时需求选择快速、标准或专业 |
| 全部 IGE | 开启 | 启用级间增益误差估计 | 用于粗校准，最终后端不参与 |
| 全部 DAC | 开启 | 启用 DAC 误差估计 | 用于粗校准，最终后端不参与 |
| 测试集比例 | 20% | 按完整采集文件随机留出的比例 | 0% 表示不从当前目录留出测试集 |

测试比例大于 0% 时至少需要两组完整采集。划分以检查结果为准，每次重新检查可能产生不同划分；比较模型时复用同一预处理任务。

## 3. 训练与运行参数

| 参数 | 教程值 | 含义 | 简要说明 |
| --- | --- | --- | --- |
| 每组读取行数 | 32768 | 每份文件的读取上限 | 0 表示读取全部行 |
| 总采样率 | 1 GHz | 频谱横轴与频率换算的依据 | 交织输入填写合并后的总采样率 |
| 窗口数量 | 3 | 一个输入窗口包含的连续时间步数 | 单通道按采样点计，交织输入按完整帧计 |
| 隐藏层 | 5 | 每个隐藏层的节点数 | `5` 表示一层五个节点；多层用逗号分隔 |
| grid | 5 | 样条网格的区间数 | 数值越大，分段越细，参数量越多 |
| k | 3 | 每段样条的多项式次数 | 一般选 2 或 3；3 表示三次样条 |
| 基础函数 | `identity` | KAN 的基础分支函数 | `identity` 为线性，`silu` 为 SiLU，`zero` 关闭该分支 |
| 训练轮数 | 20 | 对训练数据迭代的总轮数 | 早停启用时可能提前结束 |
| 批大小 | 512 | 每次参数更新使用的窗口数 | 增大通常会增加显存或内存占用 |
| 优化器 | `AdamW` | 更新模型参数的算法 | 可选 `AdamW`、`Adam` |
| 学习率 | 0.001 | 每次更新模型参数的步长尺度 | 过大可能不稳定，过小可能收敛较慢 |
| 权重衰减 | 0.0001 | 对模型参数施加的衰减强度 | 用于限制参数数值幅度，0 表示关闭 |
| 余弦周期 | 20 | 学习率降至下限所用的训练轮数 | 到达周期后保持最低学习率 |
| 最低学习率 | 0.000001 | 余弦衰减后的学习率下限 | 余弦周期结束后保持此值 |
| 目标归一化 | 开启 | 对训练的补偿目标进行标准化 | 改善优化尺度，预测输出仍为实际补偿量 |
| 早停 | 关闭 | 训练损失持续无足够改善时停止 | 按训练损失判断；阈值和耐心轮数控制触发 |
| 计算设备 | `auto`；本例实际为 CUDA | 训练使用的 CPU 或 GPU | `auto` 优先使用 CUDA，不可用时使用 CPU |
| 数值精度 | `auto`；本例实际为 `float64` | 训练使用的浮点数据类型 | 与 ADC 位宽及硬件量化位宽分别设置 |
| 随机种子 | 1 | 控制训练初始化等随机过程 | 固定后便于比较；不控制预处理的数据划分 |

指定 `cuda` 需兼容的 NVIDIA GPU；启动后核对任务显示的实际设备。

### 损失显示

<a id="loss-display"></a>

损失卡片、训练曲线和导出的损失图默认显示原始单位损失，悬停可查看标准化损失。目标标准化影响优化尺度，显示单位不影响训练或最佳模型选择。比较记录前确认损失单位一致。

## 4. 测试、搜索、剪枝与量化

| 功能 | 输入 | 输出 | 简要说明 |
| --- | --- | --- | --- |
| 独立测试 | 完整模型任务、原始采集或 `raw_test` | 逐组频谱、SNDR（dBc）、SFDR（dBc）、ENOB | 使用未参与训练或模型选择的数据 |
| 模型搜索 | 训练集、验证集、性能下限和时间预算 | 候选结构、模型与验收状态 | SNDR、SFDR 须同时达标，可按频点平均或逐组验收 |
| 模型剪枝 | 已验证模型、验证数据、增益保留比例 | 剪枝模型、连接数与验收结果 | 按校准改善量验收；自动模式仅支持单音 |
| 位宽扫描 | 浮点模型、方案选择数据、候选位宽 | 位宽方案与量化误差 | MSE 增幅相对同批数据的浮点结果计算 |
| 量化训练 | 已应用位宽、浮点模型、训练数据 | 量化模型、浮点参照、验收结果 | 仅支持单隐藏层共享网络；保留浮点参照用于硬件验证 |

测试采样率从模型读取，运行前核对信号模式与读取行数。**最终独立测试集不参与训练或模型选择**。操作步骤及验收定义见[用户手册](user-guide.zh-CN.md#optimization)。

## 5. 硬件功能

<a id="hardware"></a>

### RTL 仿真与综合

<a id="vivado-setup"></a>

**工具安装**：软件不附带 Vivado，需从 [AMD 官网](https://www.amd.com/zh-cn/support/downloads/adaptive-socs-and-fpgas/development-tools/2025-2.html)下载安装，包含 XSim 和 Virtex-7 器件支持。已验证版本为 Vivado 2025.2，综合检查目标为 `xc7vx485tffg1157-1`；按 AMD 要求配置所需许可。路径设置见[首次准备](user-guide.zh-CN.md#hardware-setup)。

在 **硬件 → 仿真与综合** 选择通过兼容性检查的量化模型，并保留完整量化任务、浮点参照及预处理配方。**补偿值输出** 供后级与基准相加；**校准值输出** 直接输出完整校准结果。

**仅生成源码** 无需 Vivado，产出 RTL 及配套材料；**生成并验证** 使用 XSim 仿真和 Vivado 综合。精度评估需独立原始采集。分别检查功能对拍、精度和综合报告。

### ASIC 实现

**额外环境**：WSL2 和独立 ASIC 扩展。扩展准备 Linux、Docker Engine、Yosys、OpenROAD、KLayout、Icarus Verilog、Verilator 及工艺资源；无需 Vivado 或 Docker Desktop。可选 IHP SG13G2（130 nm）、Nangate45（45 nm）或全部工艺，两者共用工具镜像。

按[首次准备](user-guide.zh-CN.md#hardware-setup)启用 WSL2，在 **管理 ASIC 扩展** 中选择 **在线安装** 并完成自检。预留 **至少 20 GiB 安装空间**，实验输出另计。已有环境选择 **连接已有环境**；离线导入需使用与软件版本兼容、包含所需仿真器的完整扩展包。

| 阶段 | 输出 | 简要说明 |
| --- | --- | --- |
| 逻辑综合 | 网表、面积、时序和运行状态 | 结果对应当前工艺与约束 |
| 布局布线与验证 | 物理实现及对应验证结果 | 使用同一模型、工艺和约束下的综合结果 |
| 实例功耗评估 | 数字校准电路的功耗估计 | 仅覆盖已验证电路与指定输入活动 |

比较报告时保持工艺、时钟、模型接口和输入活动一致。目标时钟是约束，实际性能以结果为准；数字校准电路功耗不包含整个 ADC 或板级系统。

失败、取消或超时后保留任务，从兼容检查点恢复。工具、工艺、模型或约束改变时，重新运行受影响阶段。硬件报告仅覆盖已完成的验证阶段。
