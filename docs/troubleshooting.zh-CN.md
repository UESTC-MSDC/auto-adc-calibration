# 故障排查：从当前步骤开始

[安装](installation.zh-CN.md) · [图解教程](quick-start.zh-CN.md) · [使用手册](user-guide.zh-CN.md)

先保存错误文本和当前任务，按下面的现象检查。每次只修改对应原因，再重试同一步。

## 软件没有正常运行

| 现象 | 先做什么 | 恢复后确认 |
| --- | --- | --- |
| 缺 DLL、双击没反应 | 校验附件，完整解压同版软件；检查系统给出的具体提示 | 主界面能打开 |
| 界面正常，任务启动失败 | 检查 Worker 是否齐全、输出目录是否可写和任务错误文本 | 一次小任务能完成 |
| CUDA 不可用或回退 CPU | 用 CPU 跑通例子，再核对 GPU 与驱动兼容性 | 任务显示实际设备 |
| 显存不足 | 将批大小从 256 降到 128，必要时再到 64 | 任务完成，记录新批大小 |

出现系统安全提示时，核对官方来源、SHA-256 和拦截原因；不要全局关闭系统防护。

## 数据检查或预处理失败

| 现象 | 优先核对 | pipelined 例子的正确值 |
| --- | --- | --- |
| 文件数或列数不对 | 是否选错目录、带表头或序号列 | `raw-train` 中 4 份文件，每份 6 列 |
| 码字越界或编码错误 | 来源、符号和位宽是否对应文件 | 各级码字、有符号十进制；前五级 2.5，末级 4 |
| 设置不能修改 | 是否已完成检查并锁定配置 | “重新开始”后修改，再检查 |
| 找不到 `raw_test` | 是否设置了 0% 测试比例 | 本例使用随附 `raw-test`，无需自动生成 |
| 提示单音拟合异常 | 信号模式、采样顺序、位宽和增益是否正确 | 单音、单通道、五个增益均为 4 |

先改输入或配置，不截断码字、拼接目录或绕过检查来掩盖错误。交织数据另需核对通道顺序与完整帧。

## 训练、测试或优化未达预期

| 现象 | 处理顺序 |
| --- | --- |
| 找不到训练数据／配对失败 | 选择预处理根目录；检查角色编号和新旧目录名；必要时重新预处理 |
| 测试缺少配方或配套文件 | 找回完整训练任务，使用其中的匹配模型 |
| 测试出现训练组 | 改选 `raw-test`；本例独立测试应只出现 003 |
| 损失下降，SNDR/SFDR 不改善 | 核对信号、采样率和读取范围；用独立原始采集逐组查看 |
| 数值与教程不完全相同 | 核对数据、版本、设备和设置；按自己的报告判断结果 |
| 位宽扫描通过，量化训练未达标 | 确认方案已应用，查看训练与最终验收的具体原因 |
| 模型不能用于某个后续功能 | 按兼容性提示选择来源，保留完整配套文件 |

## 硬件或恢复任务失败

| 现象 | 先做什么 |
| --- | --- |
| ASIC 扩展缺组件 | 运行完整自检，核对 WSL2、扩展版本与空间 |
| 超时、取消、未收敛 | 保留当前实验，查看阶段、资源和原因，再继续兼容流程 |
| 移动目录后找不到输入 | 恢复外部原始文件，或通过正常入口重新关联 |
| 报告无法比较 | 查看工艺、时钟、接口、数据和阶段的差异 |
