# 升级、备份与回退

[首页](../README.zh-CN.md) · [使用手册](user-guide.zh-CN.md)

## 升级前

1. 等待任务完成，或通过软件正常停止并保存结果。记录未完成实验与当前状态。
2. 关闭软件，备份项目目录、模型、配置、报告和恢复所需证据。
3. 单独备份项目引用的原始数据。仅复制项目目录可能漏掉外部文件。
4. 保留旧版完整软件包及其版本信息，阅读新版发行说明和兼容范围。

## 安装新版

完整解压到新的独立目录。不要把不同版本的 EXE、Worker、运行库或资源互相覆盖。

先用项目副本打开并完成一次小规模流程，检查模型、数据引用和主要结果。确认后再安排正式任务。旧项目能打开，不等于所有历史检查点都可直接继续计算。

## 模型与数据兼容

- 旧版 `code/actual/ideal` 目录具有兼容支持；新数据采用 `inputs/baseline/reference`。不要同时放置同一角色的新旧目录。
- 模型及其配套配置、参照和任务文件应一起保留，避免只拷贝单个文件。
- 恢复检查不通过时，先根据错误判断输入或版本差异；不要修改校验信息绕过检查。
- 更新 ASIC 扩展可能改变工具与工艺环境，应保留原报告及其条件记录。

## 回退

关闭新版，用保留的旧版完整软件包打开升级前的项目备份。避免把已被新版修改的项目直接当成旧版兼容副本。

软件目录、项目目录和外部采集目录分别管理。清理旧版本前核对它们之间的引用关系；旧软件可重新获取不代表用户数据可以重新生成。
