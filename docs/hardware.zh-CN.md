# RTL 与 ASIC 使用说明

[使用手册](user-guide.zh-CN.md) · [图解教程](quick-start.zh-CN.md)

## 选择工作路径

| 目标 | 入口 | 外部条件 |
| --- | --- | --- |
| 导出兼容模型 RTL | 硬件 → 仿真与综合 → 仅生成源码 | 先满足模型与参数检查 |
| RTL 仿真和综合 | 硬件 → 仿真与综合 | 配置相应外部工具路径与可用许可 |
| ASIC 工艺评估 | 硬件 → ASIC 实现 | WSL2、独立 ASIC 扩展和适用工艺库 |

应用的闭源发布范围不取消用户导出模型、RTL 和验证材料的正常功能。导出文件含有的模板或第三方内容仍适用相应许可。

## RTL 流程

选择经过验收的兼容量化模型。需要真实数据精度评估时，保留其浮点参照与预处理配方，选择原始测试采集并核对输入模式、采样率和输出语义。

“补偿值输出”表示模型校正量；“校准值输出”表示按配置组合后的校准结果。选择与后级接口实际需要一致的语义，不能只根据数值宽度判断。

执行“生成并验证”后分别查看 RTL 对拍、综合和校准结果。无相应工具时可只导出源码，但生成成功不能当作仿真或综合通过。

## ASIC 扩展

在“管理 ASIC 扩展”中选择在线安装、导入兼容离线包或连接已有环境。操作前准备 WSL2、足够磁盘和内存。扩展安装至少需要预留 20 GiB，模型实现与历史产物另计。

当前 ASIC 路线使用独立仿真运行时。旧离线包即使能导入，也可能缺少当前所需组件，应执行管理器的完整自检。只使用对应版本明确提供的资源，不把历史文件名当成仍可下载的安装入口。

## 三个阶段

1. **逻辑综合**：准备模型，执行综合并检查综合网表。
2. **布局布线与验证**：沿用兼容综合结果，执行实现和功能验证；通过后才能继续功耗步骤。
3. **实例功耗评估**：为已验证电路选择模型关联数据或手动输入数据，执行实例活动回放与功耗估计。

填写工艺、目标时钟和总时限时，保留足以完成任务的资源。教程的 20 ns 和 120 分钟只是操作示例。周期是本次约束，不是软件已证明的最高频率。

功耗数据可来自模型关联记录或手动选择。软件报告实际识别的数据与覆盖范围，应核对来源。功耗估计反映给定输入活动、工艺及电路范围，不包括整个 ADC 或板级系统，也不等于实测芯片功耗。

## 继续运行与比较

取消、失败和超时后保留已有结果，先查原因。只有模型、工具、工艺、约束及证据兼容时才能复用对应检查点。不要修改身份文件来强行恢复，也不要覆盖不同实验的结果。

比较报告时选择明确的实验与报告。条件不同或证据不完整时，应说明差异，避免给出没有共同基准的改善百分比。

## 结果边界

“未运行”“未评估”不是通过。功能对拍不覆盖所有时序、未知态和制造条件；物理流程的检查不替代代工厂 DRC/LVS 签核。没有实际执行的时序后仿与制造签核应继续标为未评估。
