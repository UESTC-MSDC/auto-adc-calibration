# RTL 与 ASIC：按目标选择流程

[使用手册](user-guide.zh-CN.md) · [故障排查](troubleshooting.zh-CN.md)

**开始条件：** 已有适用于所选硬件流程、通过相应验收的模型。保留完整模型任务、浮点参照、预处理配方及需要的原始测试数据。图解教程中的浮点训练完成后，仍需按界面要求准备兼容量化模型。

## 先选你要得到的结果

| 目标 | 入口 | 完成后应有 |
| --- | --- | --- |
| 获取 RTL 文件 | 硬件 → 仿真与综合 → 仅生成源码 | 导出的源码及配套材料 |
| 检查 RTL 功能与综合结果 | 硬件 → 仿真与综合 | 实际运行的对拍、综合与校准结果 |
| 评估目标工艺的实现 | 硬件 → ASIC 实现 | 各阶段状态、条件与报告 |

软件闭源发行不取消正常导出模型、RTL 和验证材料的功能；导出材料中的模板与第三方内容仍适用相应许可。

## 例：为已验收模型检查 RTL

1. 选择模型及所需配套文件，完成界面兼容性检查。
2. 选择输出语义：后级需要校正量时用“补偿值输出”，需要最终校准结果时用“校准值输出”。
3. 需要精度评估时，选择独立原始采集并核对输入模式、采样率和读取范围。
4. 配置仿真/综合工具路径与可用许可，运行相应验证。
5. 分别查看功能、精度与综合状态，保存完整报告。

**完成检查：** 所需阶段确实运行且结果可查看。仅生成源码时，记录为“已导出”，不记录为“仿真通过”。

## 准备 ASIC 扩展

在 **管理 ASIC 扩展** 中选择在线安装、导入兼容离线包或连接已有环境。先准备 WSL2、可用内存及至少 20 GiB 安装空间；历史实验和新任务产物另计。

执行完整环境自检。旧离线包可能缺少当前所需的仿真运行时，应按自检结果补齐。可用安装来源以当前版本说明和管理器为准。

## 三个阶段分别回答什么

| 阶段 | 要做什么 | 完成后核对 |
| --- | --- | --- |
| 逻辑综合 | 将模型映射到所选工艺库 | 网表检查、面积、时序与运行状态 |
| 布局布线与验证 | 基于兼容综合结果完成物理实现及验证 | 实现是否完成、验证是否通过 |
| 实例功耗评估 | 对已验证电路回放所选输入活动 | 数据来源、覆盖范围、功耗与条件 |

例如比较两次实验时，保持工艺、时钟、模型接口和输入数据一致，再比较同阶段报告。目标时钟是运行约束；填入某个周期不表示已经证明电路达到该频率。

## 继续任务与解释报告

失败、取消或超时后保留结果，先查看原因。通过界面恢复兼容检查点；模型、工具、工艺或约束变化时，按软件提示重新运行受影响阶段。不同实验分别保存。

| 报告状态或指标 | 可以说明什么 |
| --- | --- |
| 未运行／未评估 | 此项尚无验证结论 |
| RTL 对拍通过 | 在本次输入与检查范围内功能一致 |
| 面积／时序 | 当前工艺、约束和实现阶段的结果 |
| 活动功耗 | 当前电路范围与输入活动下的估计 |

数字校准电路的功耗不包含整个 ADC 或板级系统。功能检查与物理评估不能替代芯片实测或代工厂制造签核；未执行的检查保留为未评估。
