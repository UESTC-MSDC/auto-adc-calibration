Auto ADC Calibration 3.5.1 版本说明

日期：2026-10-20。本页记录此软件版本的变化。当前操作说明已并入用户手册和配置参考；较早下载的发行包可能仍附旧手册，可按安装说明获取配套资料。

最终输出码字与自定义权重

在预处理页面将“原始数据来源”选为“最终输出码字”，填写实际位宽 N、符号类型和文件格式。

  • 固定 N 位二进制：每行一个完整码字，不加表头、空格或分隔符；保留前导零。例如 8 位无符号码字 00000101 表示十进制 5。有符号码字按二进制补码解释，11111111 表示 -1。
  • 十进制：每行一个整数，无符号范围是 0 到 2^N−1，有符号范围是 −2^(N−1) 到 2^(N−1)−1。
  • 程序自动按 MSB 到 LSB 拆成 N 列，每列 1 bit；补码的符号位按既有规则转换。预处理文件和后续模型均按位输入，与手动拆成 N 列的处理一致。
  • 右侧使用自定义列权重，默认依次为 1、0.5、0.25……；第一个通道最高位作为权重参考。依次执行“检查数据”“扫描初始权重”和预处理。
  • “补偿基准来源”选择“粗校准后合成”时采用已接受的精确权重；选择“初始参数合成”时，权重按原有规则取最近的 2 的整数次幂。

重新打开项目后保留码字格式、位宽和权重配置。训练得到的模型在原始数据测试时使用保存的格式自动拆位，不需要再次手动拆列。已有的整码输入模型仍可按原格式测试。

显示与交互

损失卡片、训练曲线和导出的损失图默认采用原始单位损失，悬停可查看标准化损失。最佳损失仍对应训练目标选出的最佳模型；没有保存原始单位指标的旧记录不会被错误标成真实损失。

频谱图在输入区域展开和收起时都使用适当的图表比例，减少滚轮切换时的重复绘制和卡顿。

导入空权重、非有限或非正权重会显示配置错误并保留当前页面配置；ADC 数据配置中的 NaN 和无穷大位宽或增益会在读取时被拒绝。

启动

将整个发行目录放在可写位置，运行 KAN Workbench.exe。请保留同目录中的 KAN Worker.exe、_internal、configs 和 Documentation，程序依赖这些配套文件。
